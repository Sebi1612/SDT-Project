# Generate the multilingual results

Run from the repository root in the configured project environment (`attention/requirements.txt`, `DirectProbe/requirements.txt`, and `pip install -e DirectProbe`; Tree-sitter must be `0.20.1`). Model checkpoints must be cached for the offline staged runners. Run sections in order. Commands use separate reproduction directories and do not recompute Python results.

## 1. Attention analysis

CodeBERT, Java/Go/JavaScript, all 3,000 programs:

```bash
export MPLBACKEND=Agg
export OMP_NUM_THREADS=4
export MKL_NUM_THREADS=4
export OPENBLAS_NUM_THREADS=4
export TOKENIZERS_PARALLELISM=false

python attention/build_parsers.py --languages java go javascript

python attention/run_section_3_2.py \
  --languages java go javascript \
  --dataset_dir attention/exp_data/final_3000 \
  --graph_root graph_info/reproduction_codebert \
  --results_root analysis_results/reproduction/attention_final_3000 \
  --expected_count 3000 --device cpu --seed 0 --skip_ged
```

Other five models (also generates their t-SNE results; requires at least 35 GB free disk):

```bash
python attention/run_staged_model_analysis.py \
  --models graphcodebert unixcoder plbart codet5 codet5p_220 \
  --languages java go javascript \
  --dataset_root attention/exp_data/final_3000 \
  --graph_stage_root graph_info/reproduction_adapters \
  --embedding_stage_root structural_probe/reproduction_adapters \
  --results_root analysis_results/reproduction/final_3000_multimodel \
  --run_manifest analysis_results/reproduction/final_3000_multimodel/run_manifest.json \
  --expected_programs 3000 --tsne_layer 5 --device cpu
```

## 3. t-SNE

CodeBERT, using the graphs from section 1. The other five models' t-SNE outputs are generated by the staged command in section 1.

```bash
for language in java go javascript; do
  python attention/save_word_embedding.py \
    --model codebert --lang "$language" \
    --code_file "attention/exp_data/final_3000/${language}.jsonl" \
    --graph_loc "graph_info/reproduction_codebert/${language}/codebert" \
    --save_dir structural_probe/reproduction_codebert \
    --exp_name final_3000 --device cpu --seed 0 || break

  python attention/hidden_tsne.py \
    --lang "$language" \
    --embedding_dir "structural_probe/reproduction_codebert/${language}/final_3000/codebert" \
    --save_dir "analysis_results/reproduction/${language}/tsne/final_3000" \
    --layers 5 --token_perplexities 50 --distance_perplexities 5 10 \
    --min_tokens 100 --max_programs 100 --program_selection shortest \
    --iterations 50000 --seed 0 || break
done
```

## 4. DirectProbe

Prepare CodeBERT datasets from sections 1 and 3, using the retained manifests' sampling settings:

```bash
python - <<'PY'
import json
import subprocess
import sys
from pathlib import Path

for language in ("java", "go", "javascript"):
    for task in ("distance", "distance_id", "siblings", "siblings_id", "dfg"):
        path = Path("DirectProbe/final_3000/data") / language / task / "codebert/dataset_manifest.json"
        settings = json.loads(path.read_text())
        subprocess.run([
            sys.executable, "attention/create_multilingual_dp.py",
            "--task", task, "--lang", language, "--model", "codebert",
            "--graph_dir", f"graph_info/reproduction_codebert/{language}/codebert",
            "--embedding_dir", f"structural_probe/reproduction_codebert/{language}/final_3000/codebert",
            "--output_root", "DirectProbe/reproduction_final_3000",
            "--layers", "5", "9", "12",
            "--target_per_label", str(settings["selected_per_label"]),
            "--max_programs", str(settings["num_programs_considered"]),
            "--seed", str(settings["seed"]), "--require_target",
        ], check=True)
PY
```

Prepare GraphCodeBERT and CodeT5 datasets (requires at least 55 GB free disk):

```bash
python attention/run_staged_directprobe_preparation.py \
  --models graphcodebert codet5 --languages java go javascript \
  --dataset_root attention/exp_data/final_3000 \
  --graph_stage_root graph_info/reproduction_directprobe \
  --embedding_stage_root structural_probe/reproduction_directprobe \
  --output_root DirectProbe/reproduction_final_3000 \
  --run_manifest DirectProbe/reproduction_final_3000/preparation_manifest.json \
  --expected_programs 3000 --device cpu
```

Run all tasks/models at layers 5, 9, and 12. Requires `gurobipy` and a working Gurobi license; replace the license path:

```bash
GRB_LICENSE_FILE=/absolute/path/to/gurobi.lic \
python DirectProbe/run_multilingual_pilot.py \
  --dp_dir DirectProbe --pilot_root DirectProbe/reproduction_final_3000 \
  --languages java go javascript --models codebert graphcodebert codet5 \
  --tasks distance distance_id siblings siblings_id dfg --layers 5 9 12 \
  --workers 4 --timeout 172800 --required_solver gurobi \
  --quarantine_incomplete --manifest_name directprobe_reproduction_manifest.json
```
