# Result provenance

Three kinds of evidence appear in the comparison and must not be conflated.

## 1. Original Python paper outputs

The public repository
<https://github.com/stg-tud/code-LLM-critical-evaluation> was checked at commit
`87841113b0cf823aaa74295351b040bd2f56b707` (2024-05-27).

It contains:

- 968 stored attention/DFG/GED comparison files under
  `attention/graph_comparision/`;
- 638 DirectProbe result files under `DirectProbe/results/`, including 159
  published `prediction.txt` outputs;
- `exp_0.jsonl`, the 3,000-program Python cohort;
- the two result notebooks and generated paper PDFs.

The upstream README explicitly states that the DirectProbe results and
intermediate comparison results used by the paper are provided. A file-level
comparison found the local `attention/graph_comparision/` identical to the
upstream tree. The local `DirectProbe/results/` matches the upstream outputs and
additionally contains completed files for `distance/codegen/8`, whose upstream
directory contains only a log.

The upstream repository does **not** include the large `graph_info/`,
`structural_probe/`, or original `DirectProbe/data/` directories. Therefore it
provides the paper's result outputs and enough material to reconstruct figures
and tables, but not every raw tensor or feature matrix required to rerun all
experiments without regenerating model representations.

## 2. Recomputed Python outputs

The project recomputed final-3000 Python attention overlap and t-SNE results for
the six comparison models. These are used in the four-language attention and
t-SNE figures. Five models closely reproduce the stored paper curves; PLBART
has a larger unresolved AST-recall discrepancy documented in the validation
audit.

Python GED and DirectProbe values in the comparative manuscript use the stored
original paper outputs, not a new complete Python solver rerun.

## 3. New multilingual outputs

Java, JavaScript, and Go attention, GED, t-SNE, and DirectProbe outputs were
generated by this project. Manifests and validation files are linked by
`RESULT_INVENTORY.csv`. GED and probing were intentionally limited to CodeBERT,
GraphCodeBERT, and CodeT5.

## Source-of-truth rule

The compact files in `report/` are for review. The path in each
inventory row's `primary_output` column is the authoritative result. The
`provenance` column states whether it is an original paper result, a Python
recomputation, or a new multilingual run.
